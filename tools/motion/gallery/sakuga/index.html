Sakuga, with claws

All twelve controls from Sakuga VFX (two are buttons), rebuilt natively for Purrperty in cherry and gold and recorded on the simulator. Nothing is in the real screens yet. Choose for each, then copy your picks.

Buttons

Squashes flat, flashes dark for a frame, then a burst, chips and POW! A cat-eared smoke ring drifts off. The secondary one just flicks three whiskers.

Where it would go Main actions only: Record Payment, Create account, Add property, Start trial. Secondary style for Cancel and Not now.

Buttons

Toggle

The painted splash, recoloured cherry, with a paw on the knob at rest.

Where it would go Settings: sound, haptics, weather, alerts.

Toggle

Slider

A paw thumb. Drag fast for clouds and ZOOM; let go at speed and it leaves claw marks.

Where it would go Copilot proactiveness (the only slider in the app today).

Slider

Checkbox

Three claws swipe the box, chips fly, the tick draws itself.

Where it would go Home tasks, and move-in or move-out lists.

Checkbox

Radio

A paw spins in, smoke pops in the shape of a paw.

Where it would go Payment method, theme, Purr’s look, request priority.

Radio

Text input

Every key kicks up dust; a space or ! puffs a paw.

Where it would go Sign-up and first-property fields. Not long messages.

Tabs

The raised tab has cat ears; it slides, squashes and lands.

Where it would go Property and tenant detail tabs, rent filters.

Progress

Where it would go 1.8 Building, saving a property, uploads.

Rating

Paws light one by one; five earns PURRFECT!

Where it would go Rating a repair. The app has no ratings yet, so this needs a small feature.

Toast

Where it would go Every success message. Errors stay calm.
